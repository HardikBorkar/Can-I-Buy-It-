## 1. Challenge Overview & Context

PayPal powers money movement for millions of businesses and consumers globally. This hackathon opens up PayPal's platform to explore what happens when AI takes the wheel: new autonomous agents, intelligent payment flows, and tools not yet conceived.

There are **no rigid tracks or pre-defined problem statements**. Builders are invited to create an agent, an application, an automation, a merchant workflow, or an entirely new payment interaction.

### The Fundamental Requirement
> **Your project must meaningfully integrate both PayPal and AI.**

---

## 2. What You Can Build (Inspiration Areas)

1. **AI Agents & Autonomous Commerce**
   - Autonomous agents that transact on behalf of users (not just recommend).
   - Agent-to-agent (A2A) commerce, where AI agents negotiate, verify terms, and settle payments automatically.
   - Task completion triggers: Assistants that disburse funds to freelancers or service providers upon verified task completion.
   - Shopping assistants that discover items, verify stock/pricing, and complete checkout.

2. **Money Movement Experiences**
   - Faster, simpler, or more intuitive money transfer methods.
   - Instant receipt-splitting with AI OCR & automated payment requests.
   - Multi-cause donation splitting in a single payment.
   - Payout engines for gig workers immediately upon approval.

3. **Business & Merchant Solutions**
   - Multi-currency dynamic invoicing for global freelancers.
   - Intelligent dispute triage & evidence compilation for merchants.
   - Automated revenue splitting between marketplaces and independent sellers.
   - AI bookkeeping, refund-spike monitoring, and cash flow forecasting.

4. **Consumer Financial Experiences**
   - AI-driven personal budgeting and expense categorization.
   - Conversational checkout flows embedded inside messaging apps.
   - Tailored payment flows designed for underserved groups (students, seniors, accessibility-first).

5. **Social Impact & Inclusion**
   - Accessible donation experiences with screen-reader and multilingual voice interfaces.
   - Microloans and community pool funds (e.g., local solar co-ops or neighborhood funds).

## 3. Project & Submission Requirements

### What Your Project Must Have:
- **Meaningful PayPal Integration:** Integrate at least one PayPal technology, API, SDK, product, or developer capability (using the free PayPal Sandbox).
- **Meaningful AI Integration:** Incorporate an AI tool, LLM model, autonomous agent framework, or vector search into the core user experience or backend logic.
- **Working Prototype:** A functional proof-of-concept that judges can actually test or run.

### Submission Deliverables:
1. **Public Code Repository:** GitHub, GitLab, or Bitbucket containing all code, setup instructions, and an open-source license.
2. **Functional Demo:** Either:
   - A live, hosted demo URL, **OR**
   - Complete, step-by-step instructions in the repository allowing judges to build and run the application locally.
   - *(Note: Static mockups or non-functional wireframes are disqualified).*
3. **Demo Video:**
   - Under 3 minutes.
   - Must be uploaded to YouTube and set to Public or Unlisted.
   - Must show the working application in real-time on its intended device/interface.
4. **Project Story & Tooling Breakdown:** Text description explaining features, problems solved, and which AI models/services were utilized.

---

## 4. Judging Criteria

| Criterion | Description |
| :--- | :--- |
| **Technological Implementation** | How thoroughly and skillfully does the project use the PayPal Developer Platform and AI tools? Is it a robust, working, non-trivial technical build? |
| **Design** | Does the project deliver a complete, coherent, intuitive user and product experience rather than a bare technical prototype? |
| **Potential Impact** | Does the project solve a real problem for a specific target audience, and does the demonstrated solution credibly address that problem? |
| **Innovation & Creativity** | How novel, original, and differentiated is the idea compared to existing financial or payment tools? |
| **Presentation** | Does the video clearly communicate what problem is solved, who it's for, and demonstrate end-to-end functionality? |
