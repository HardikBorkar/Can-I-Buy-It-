# Guardian Financial Copilot AI

## My Role in the Project
I am designing the frontend user interface and preparing the PayPal integration research for the "Can-I-Buy-It?" AI agent.

## Agent Capabilities
- **Affordability Check:** Analyzes the user's current sandbox balance against their upcoming rent and bills (the 90-day safety buffer).
- **Payment Strategy:** Helps users decide whether to buy a product outright or use instalments.
- **PayPal Integration:** Replaces simulated data with actual PayPal API data.

## PayPal APIs to Integrate
- **Sandbox Testing:** For safely testing simulated transactions.
- **Orders & Payments API:** To securely process the purchase.
- **Pay Later:** To offer flexible instalment options when upfront payment is unsafe.

## Frontend UI Plan
- Retain the existing backend logic.
- Redesign the financial dashboard using Next.js, shadcn/ui, and Aceternity UI to give the agent a polished, professional look.
